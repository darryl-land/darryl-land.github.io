Simple YT Video Downloader

Another very very very simple and easy to use PyQt6 video downloader app that uses yt-dlp

Features

  • Uses PyQt6
  • Downloads video using yt-dlp
  • Live console ouput of yt-dlp downloading video
  • Option to enable embedding auto-generated english captions
  • Options to either mark segments or remove sponsors with SponsorBlock
  • Installs yt-dlp if it is not installed
  • Updates yt-dlp with a button

Get Started

Download and install the AppImage or Flatpak from the Releases page

Or install the dependencies required:

  • Python 3.14 or higher
  • PyQt6

Then git clone and run the app

git clone https://github.com/darryl-land/simpleytvideodownloader.git
cd simpleytvideodownloader
python3 app.py
